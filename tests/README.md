# Тесты hsb-screenshoot

Запускать в каталоге плагина, при выключенном захвате из DSH не обязателен — тесты берут свои порты.

| Скрипт | Что проверяет |
|---|---|
| `node tests/probe.mjs` | бэкенд платформы напрямую: мониторы, окна, три вида снимков |
| `node tests/smoke.mjs` | инструменты через `index.js`: регистрация, схемы, вызовы |
| `node tests/frames.mjs` | сервер кадров: маркер `[shot:<id>]`, отдача PNG по HTTP |

## Замечания

- `probe.mjs` работает только на Windows (импортирует `src/win32.js`); на macOS/Linux замените импорт на `src/darwin.js` / `src/linux.js`.
- `smoke.mjs` и `frames.mjs` платформенно-независимы: `index.js` сам выбирает бэкенд.
- Порт сервера кадров в тестах отличается от рабочего (`49298`/`49299`), чтобы не конфликтовать с запущенным DSH.
- Требования платформы — в основном README.
